# papers

Annotated readings of research papers: the original text on the left, and on the right
a stack of explanations for everything the paper assumes you already know.

Each reading is a single self-contained HTML file. Open `index.html` for the list.

```
index.html                    the list of papers
llm/kimi-k3/index.html        Kimi K3: Open Frontier Intelligence
crypto/dylean/index.html      Bob DyLean: Symbolic Analysis of Cryptographic Protocols in Lean
```

Adding a paper: make a folder under a topic directory (`llm/`, `crypto/`, …), drop in
`index.html` plus any `figures/`, and add a row to the root `index.html`.
